# Primor Móveis

Site institucional e portfólio da Primor Móveis, marcenaria especializada em móveis planejados sob medida em Belo Horizonte e região metropolitana.

## Site publicado

https://primor-moveis-bh.jaunty-llama-6894.chatgpt.site

## Recursos

- página inicial responsiva;
- portfólio filtrável por ambiente;
- páginas individuais de projetos;
- apresentação da empresa;
- formulário de solicitação de orçamento;
- contato direto pelo WhatsApp;
- SEO local para Belo Horizonte;
- navegação acessível por teclado;
- suporte a preferência por movimento reduzido;
- experiência otimizada para celulares.

## Tecnologias

- TypeScript;
- React;
- Vinext/Vite;
- CSS responsivo;
- Cloudflare Workers para hospedagem e formulário.

## Desenvolvimento local

Requer Node.js 22.13 ou superior.

```bash
npm install
npm run dev
```

O ambiente local é iniciado em `http://127.0.0.1:5173`.

Para verificar a versão de produção:

```bash
npm run build
```
